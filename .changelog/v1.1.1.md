# Changelog

## 1.1.1 - 2026-09-20

Patch focused on the Staff of Authority interaction reliability.

### Fixes

- Fixed a bug where using the Staff of Authority on a chest could target the block below or behind the chest.
- Block interactions now use `ItemComponentUseOnEvent.block`, which provides the exact block that received the item use.
- Companion/entity interaction remains handled through `onUse` and the entity view-direction query.
- Added a one-tick arbitration guard so a block click is not processed again as an entity interaction.

### Documentation

- Updated the README for version 1.1.1 and documented Staff of Authority interactions.
- Added a dedicated CurseForge description file (`CURSEFORGE.md`).
